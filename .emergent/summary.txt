<analysis>**original_problem_statement:**
The user wants to build a Motesart Number System Converter application. The core functionality is to allow users to upload music files (Image, PDF, MusicXML, MIDI, HEIC) or enter chord charts manually, have the system auto-detect the key, notes, and chords, and then convert this information into the Motesart Number System.

**PRODUCT REQUIREMENTS:**
- **Inputs:** Support various file types (JPG, PNG, PDF, MIDI, MusicXML, HEIC) and manual text entry of chord charts.
- **Conversion Logic:** Implement the T.A.M.i rules from the user-provided methodology documents. This includes key detection, note-to-number mapping (including half-numbers), chord quality inference (m, M, ᵒ, ⁺), extensions (⁷, ⁹), and inversions (e.g., 1/3).
- **Visual Outputs:** The application must provide two main visual output formats on-screen before download:
    - **Format A (Staff Notation):** For sheet music uploads, render the original staff with Motesart numbers replacing the note heads, preserving rhythm and vertical position.
    - **Format B (Lead Sheet):** For chord chart inputs, display a clean text-based layout with Motesart numbers above the corresponding lyrics.
- **Dashboard & UI:**
    - A reorganized dashboard with a primary focus on the visual Motesart Conversion panel.
    - A collapsible Original File Preview at the bottom.
    - AI Explain and Chat panels for interacting with the conversion.
    - A Manual Entry button as a fallback for failed OMR.
    - A separate /converter page for text-based conversion.
- **OMR (Optical Music Recognition):** The system must attempt to extract key, chords, notes, and lyrics from uploaded PDF/Image/HEIC files. This has been a persistent problem area.
- **Authentication:** A complete user account system with Google Auth and email/password, including a multi-user avatar system with special handling for the Motesart founder account (crown icon).
- **Export:** Users should be able to export the visual conversion as PDF, PNG, and copy the text. The exported file must match the on-screen preview.
